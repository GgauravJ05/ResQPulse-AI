# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the work. Harassment or
discrimination of any kind is not tolerated.

Report unacceptable behaviour by opening a private report to the maintainer (see [SECURITY.md](SECURITY.md) for how to
reach us). Reports are handled confidentially.
